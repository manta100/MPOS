================================================================================
                    MPOS - IMPLEMENTATION PLAN
                    Modern Point of Sale System
================================================================================

PROJECT OVERVIEW
================================================================================
MPOS (Modern Point of Sale) is a full-stack POS system inspired by Loyverse POS,
designed for retail and restaurant businesses.

TECHNOLOGY STACK
================================================================================
- Frontend: React 18 + Vite + TypeScript + Tailwind CSS + Zustand
- Backend: Node.js + Express + TypeScript
- Database: MySQL 8.0+ with Prisma ORM
- Real-time: Socket.io
- Auth: JWT with refresh tokens
- PWA: vite-plugin-pwa

================================================================================
                    HOW TO RUN THE PROJECT
================================================================================

PREREQUISITES
================================================================================
- Node.js 18 or higher
- MySQL 8.0 or higher
- npm or yarn

OPTION 1: LOCAL DEVELOPMENT (RECOMMENDED)
================================================================================

Step 1: Clone the repository
-----------------------------
git clone https://github.com/manta100/MPOS
cd MPOS

Step 2: Setup Backend
---------------------
cd backend
npm install
cp .env.example .env

# Edit .env with your MySQL credentials:
# DATABASE_URL="mysql://user:password@localhost:3306/mpos"
# JWT_SECRET="your-secret-key"
# JWT_REFRESH_SECRET="your-refresh-secret"
# PORT=3001
# FRONTEND_URL="http://localhost:5173"

# Generate Prisma client
npx prisma generate

# Push schema to database
npx prisma db push

# Start backend server
npm run dev
# Backend runs on http://localhost:3001

Step 3: Setup Frontend (new terminal)
-------------------------------------
cd ../frontend
npm install

# Start frontend
npm run dev
# Frontend runs on http://localhost:5173


OPTION 2: DOCKER
================================================================================

cd MPOS

# Start all services (MySQL, Backend, Frontend)
docker-compose up -d

# Services:
# - Frontend: http://localhost:5173
# - Backend: http://localhost:3001
# - MySQL: localhost:3306 (root/root)
